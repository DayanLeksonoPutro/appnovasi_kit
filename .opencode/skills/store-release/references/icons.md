# Launcher icon and store graphics

`scripts/generate_icons.py` turns `store/brand.json` into every icon the app and the Play listing
need. It is deterministic: same brand.json in, same bytes out, so it can be re-run on every app
without a designer in the loop.

## brand.json

```json
{
  "app_name": "Pas Foto",
  "package_id": "com.appnovasi.pasfoto",
  "monogram": "PF",
  "background": "#2563EB",
  "background_end": "#0EA5E9",
  "foreground": "#FFFFFF",
  "wordmark": true
}
```

- `monogram`: 1–3 characters. Monogram beats a full wordmark — the launcher shows 48 dp.
- `background` / `background_end`: gradient endpoints. Pull them from the app's theme config so the
  icon cannot drift away from the product.
- `wordmark`: when `true`, the 1024×500 feature graphic gets the app name under the logo.

## Usage

```bash
python3 scripts/generate_icons.py <app-root>                # launcher + Play assets
python3 scripts/generate_icons.py <app-root> --play-only    # only store/assets/
STORE_ICON_FONT=/path/to/font.ttf python3 scripts/generate_icons.py <app-root>
```

## Outputs

| Output | Size | Uploaded? |
|---|---|---|
| `res/mipmap-{m,h,xh,xxh,xxxh}dpi/ic_launcher.png` | 48 / 72 / 96 / 144 / 192 | no, launcher |
| `res/mipmap-*/ic_launcher_round.png` | same | no, launcher |
| `res/mipmap-*/ic_launcher_foreground.png` | 108–432 (2.25× legacy) | no, launcher |
| `res/mipmap-anydpi-v26/ic_launcher.xml` + `_round.xml` | adaptive icon | no |
| `res/values/ic_launcher_background.xml` | colour | no |
| `store/assets/icon_512.png` | 512×512, opaque RGB | **yes**, app icon |
| `store/assets/feature_graphic_1024x500.png` | 1024×500 | **yes**, feature graphic |

## Rules baked into the generator

- **Adaptive icon safe zone**: the 108 dp adaptive canvas is masked by the launcher; only the centre
  72 dp (66%) is guaranteed visible. The foreground monogram is drawn at `0.30 × 2/3` of the canvas,
  so it survives circular, squircle and rounded-square masks.
- **Play icon must be opaque**: the 512 asset is flattened to RGB with no alpha channel. Play rejects
  transparency in the listing icon.
- **Play applies its own mask**: the 512 icon is square and full-bleed. The rounded corners only exist
  in the legacy launcher icon, where the launcher may add its own.
- **`monochrome`** is included in the adaptive XML so Android 13+ themed icons work.

## Font resolution order

1. `--font` argument
2. `$STORE_ICON_FONT`
3. `assets/fonts/Poppins-Bold.ttf`, `Poppins-SemiBold.ttf`, `Inter-SemiBold.ttf`,
   `Manrope-Variable.ttf` relative to the app root, then the workspace root
4. System bold fonts (Arial Bold / Helvetica / DejaVu Sans Bold)
5. Pillow's bitmap default — legibility will be poor; set `STORE_ICON_FONT`

## Screenshots

Screenshots are **not** generated by the script: they are real UI. Capture them on a device or
emulator at 1080×1920 and place them in `store/assets/screenshots/phone/NN-name.png`, then list the
files in `store.json → assets.screenshots` so `store_tool.py validate` can find them.

Capture rules that measurably lift conversion:

1. First screenshot = the single strongest promise, in the app's own UI style, one line of bold text
   at the top.
2. 2–8 screenshots, 4 is usually enough for a single-job utility.
3. No device frames, no marketing gradients, no stock photos — Play rejects screenshots that are not
   the app.
4. Every screenshot caption ≤ 12 words, readable at thumbnail size.
5. Recapture when the UI changes; stale screenshots are the most common source of bad ratings.
